# 共轴多旋翼动力学与运动学仿真系统设计

## 日期
2026-05-21

## 目标
基于 `model.md`、`controller.md`、`closed_loop_system.md` 构建完整的共轴八旋翼闭环仿真系统。

## 架构（方案A：面向对象模块化）

```
指令输入 [pos_cmd, yaw_cmd]
    │
    ▼
┌─────────────────┐
│   Controller    │  ← 理想状态反馈（第一版无观测器）
│                 │
│  • 水平位置环   │  PID(1,0,0) → 速度指令
│  • 水平速度环   │  PID(1,0.02,0) → 加速度 → {roll_cmd, pitch_cmd}
│  • 高度环       │  PID(0.7,0,0) → 速度指令
│  • 速度环       │  PID(2,0,0) → 加速度指令
│  • 加速度环     │  100*PID(0.1,2,0) → servo_thro（含倾角补偿）
│  • 滚转角       │  PID(5,0,0) → 角速度指令
│  • 滚转角速度   │  100/7*PID(0.1,0.05,0)*LeadLag → servo_roll
│  • 俯仰角       │  PID(5,0,0) → 角速度指令
│  • 俯仰角速度   │  100/7*PID(0.1,0.05,0)*LeadLag → servo_pitch
│  • 偏航角       │  PID(2,0,0) → 角速度指令
│  • 偏航角速度   │  100/10*PID(0.3,0.1,0) → servo_yaw
│                 │
│  • 控制分配     │  M1~M8（含PWM限幅[0,1000]）
└────────┬────────┘
         ▼
┌─────────────────┐
│ Actuator Model  │
│  电机一阶 2Hz   │  PWM→转速→拉力/扭矩
│  下层出力×0.67  │
└────────┬────────┘
         ▼
┌─────────────────┐
│  Rigid Body Dynamics │
│  6DOF, 惯量(67,67,75)kg·m² │
│  质量 400kg（可配置）      │
│  欧拉积分 / RK4            │
└────────┬────────┘
         ▼
┌─────────────────┐
│  Sensor Suite   │
│  IMU (杆臂效应)  │
│  RTK1/RTK2 (位置+航向) │
│  Barometer      │
└─────────────────┘
```

## 关键参数

| 参数 | 值 | 备注 |
|------|-----|------|
| 质量 | 400 kg | 默认，可配置（未在文档明确给出） |
| 惯量 | diag(67, 67, 75) kg·m² | 主惯量积 |
| 电机数量 | 8 | 上层M1~M4，下层M5~M8 |
| 单电机最大拉力 | 100 kg | @ 1800 rpm |
| 单电机最大扭矩 | 80 Nm | @ 1800 rpm |
| 力臂 | x=±1m, y=±1m | 滚转/俯仰力臂 |
| 电机带宽 | 2 Hz | 一阶环节 |
| 仿真步长 | 0.001 s (1 ms) | 保证数值稳定性 |

## 设计决策

1. **上下层出力差异**：在 `ActuatorModel` 中处理，下层实际拉力 = 标称拉力 × 0.67。
2. **Lead-Lag 离散化**：采用状态空间法连续积分（因动力学本身也是连续ODE）。
3. **角度单位**：控制器内部使用 deg，与动力学接口处统一转换为 rad。
4. **水平通道映射**：小角度近似 `roll_cmd ≈ a_y/g`, `pitch_cmd ≈ -a_x/g`。
5. **控制分配限幅**：先计算分配，再对每个电机独立限幅[0,1000]。

## 测试策略

- `test_step_position`：位置阶跃响应
- `test_step_altitude`：高度阶跃响应
- `test_step_yaw`：偏航阶跃响应
